# Break the Chain - Clinical Safety Missions

An English-language interactive learning experience that turns 13 clinical
incidents into 11 short safety missions for fresh graduate nurses.

Mission Stars are based only on the Part 1 decision in each mission and are for
fun only. Training completion is confirmed by the Final Quiz.

This repository contains the public static website published through GitHub
Pages. No visitor login is required.

Public website:
https://sincekong.github.io/break-the-chain-clinical-safety-missions/
